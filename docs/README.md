## 구현 기능 목록

### 문자열 입력
- [ ] 사용자로부터 덧셈할 문자열을 입력받는다.


---

### 입력 형식 판별
- [ ] "//"로 시작하는 경우 커스텀 구분자 형식으로 판별한다.
- [ ] 숫자로 시작하는 경우 기본 구분자 형식으로 판별한다.
- [ ] 빈 문자열("")인 경우 0으로 문자열을 변경한다.

#### 예외 처리
- [ ] "//"로 시작하지도 않고 숫자로 시작하지도 않으면 `IllegalArgumentException` 발생

---

### 커스텀 구분자 추출
- [ ] "//"와 "\n" 사이의 문자열을 구분자로 추출한다.
- [ ] "\n" 이후의 문자열을 숫자 문자열로 추출한다.

#### 예외 처리
- [ ] "\n"이 존재하지 않으면 `IllegalArgumentException` 발생

---

### 문자열 분리
- [ ] 커스텀 구분자인 경우 해당 구분자로 문자열을 분리한다.
- [ ] 기본 구분자인 경우 쉼표(,) 또는 콜론(:)으로 문자열을 분리한다.
- [ ] 분리 결과가 비어있으면 0을 반환한다.

---

### 숫자 변환 및 덧셈
- [ ] 분리된 각 문자열을 정수로 변환한다.
- [ ] 모든 숫자의 합을 계산한다.

#### 예외 처리
- [ ] 음수가 포함된 경우 `IllegalArgumentException` 발생
- [ ] 숫자로 변환할 수 없는 경우 `IllegalArgumentException` 발생

---

### 결과 출력
- [ ] "결과 : {합계}" 형식으로 출력한다.

---

## 테스트 케이스 예시

### 정상 케이스
```
입력: ""              → 출력: 결과 : 0
입력: "1,2,3"         → 출력: 결과 : 6
입력: "1,2:3"         → 출력: 결과 : 6
입력: "//;\n1;2;3"    → 출력: 결과 : 6
입력: "//;\n"         → 출력: 결과 : 0
```

### 예외 케이스
```
입력: "abc"           → IllegalArgumentException (형식 오류)
입력: "/1,2,3"        → IllegalArgumentException (형식 오류)
입력: "//;1;2;3"      → IllegalArgumentException (\n 없음)
입력: "1,-2,3"        → IllegalArgumentException (음수)
입력: "//;\n1;a;3"    → IllegalArgumentException (숫자 아님)
```
