## 구현 기능 목록

### 문자열 입력
- [x] 사용자로부터 덧셈할 문자열을 입력받는다.

---

### 입력 형식 판별
- [x] "//"로 시작하고 "\n"을 포함하면 커스텀 구분자 형식
- [x] 그 외의 경우 기본 구분자 형식으로 처리
  (숫자로 시작하지 않아도 기본 구분자로 시도 → 변환 실패 시 예외)

---

### 커스텀 구분자 추출
- [x] "//"와 "\n" 사이의 문자열을 구분자로 추출한다.
  (형식이 맞지 않더라도 기본 구분자로 시도 → 변환 실패 시 예외)
- [x] 구분자 유효성 검증
  - 1글자만 허용 (요구사항 예시: //;\n)
  - 모든 특수문자 허용 (;, |, * 등)
  - 한글/영어 허용 (가, ㄱ, ㄴ, a, b, c 등)
- [x] "\n" 이후의 문자열을 숫자 문자열로 추출한다.

#### 예외 처리
- [x] 구분자가 숫자라면 `IllegalArgumentException` 발생
- [x] 구분자가 비어있거나 띄어쓰기로 되어있다면 `IllegalArgumentException` 발생
- [x] 구분자의 길이가 2 이상이라면 `IllegalArgumentException` 발생
---

### 문자열 분리
- [x] 커스텀 구분자인 경우 해당 구분자로 문자열을 분리한다.
- [x] 기본 구분자인 경우 쉼표(,) 또는 콜론(:)으로 문자열을 분리한다.
- [x] 분리 결과가 비어있으면 빈 리스트를 반환한다.

---

### 숫자 변환 및 덧셈
- [x] 분리된 각 문자열을 정수로 변환한다.
- [x] 모든 숫자의 합을 계산한다.

#### 예외 처리
- [x] 음수가 포함된 경우 `IllegalArgumentException` 발생
- [x] 숫자로 변환할 수 없는 경우 `IllegalArgumentException` 발생 (값 초과, 문자 등등)

---

### 결과 출력
- [x] "결과 : {합계}" 형식으로 출력한다.

---

## 테스트 케이스 예시

### 정상 케이스
```
입력: ""              → 출력: 결과 : 0
입력: ","             → 출력: 결과 : 0
입력: ",,,"           → 출력: 결과 : 0
입력: "1,,3"          → 출력: 결과 : 4
입력: "1,2:3"         → 출력: 결과 : 6
입력: "//;\n1;2;3"    → 출력: 결과 : 6
입력: "//;\n"         → 출력: 결과 : 0
입력: "//;\n;;"       → 출력: 결과 : 0
```

### 예외 케이스
```
입력: "abc"           → IllegalArgumentException (형식 오류)
입력: "#"             → IllegalArgumentException (형식 오류)
입력: "/1,2,3"        → IllegalArgumentException (형식 오류)
입력: "//;1;2;3"      → IllegalArgumentException (\n 없음)
입력: "// \n1 2 3"    → IllegalArgumentException (구분자가 없음)
입력: "1,-2,3"        → IllegalArgumentException (음수)
입력: "//;\n1;a;3"    → IllegalArgumentException (숫자 아님)
```
